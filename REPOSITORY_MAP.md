# Repository Map

## `phases/`
Primary phase-level records organized chronologically. Phase 3 contains multiple companion documents because the project developed through distinct expression and methods records. Phase 5 contains an archival-status README because a separate byte-accessible standalone full master report was not present when the repository was packaged.

## `release/`
Canonical integrated APA 7 master document. This is the most complete single-file representation of the six-phase project.

## `references/`
Consolidated APA 7 reference list assembled from the phase bibliographies.

## `appendices/`
Vocabulary and formulas appendix defining technical terms, formulas, model variables, and interpretive cautions.

## `summaries/`
Five-page nontechnical summary intended for readers who need the premise, phase-by-phase results, and final conclusions without full technical detail.

## `metadata/`
Project facts, provenance notes, and cryptographic checksums.

## `scripts/`
Placeholder documentation for future reproducible analysis code. No unavailable analysis script has been fabricated for this release.
