# Contributing and Scientific Revision Policy

This repository is a frozen scientific record. Contributions are welcome when they improve reproducibility, identify errors, add verifiable evidence, or support a formally reopened analysis.

## Required discipline

1. Do not silently modify frozen conclusions.
2. Distinguish correction from reinterpretation.
3. Record genome build, transcript/annotation version, data release, accession, software version, parameters, and access date where relevant.
4. Distinguish heterozygous deletion, heterozygous loss-of-function, hypomorph, biallelic loss, knockout, dominant-negative, gain-of-function, and pharmacologic perturbation.
5. Do not treat expression as dysfunction or pathway membership as causal interaction.
6. Retain contradictory, null, and negative results.
7. Do not convert missing evidence into a zero or negative result.
8. For causal claims, state the highest directly supported evidentiary layer.

## Pull requests

A pull request affecting scientific interpretation should state:

- prior frozen conclusion;
- new evidence;
- model/tissue/genotype state;
- source and identifier;
- whether it contradicts, refines, or extends the prior record;
- whether an erratum, reinterpretation, or new version is warranted.
